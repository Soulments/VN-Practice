# VN-Practice

Unity 6 비주얼 노벨 연습 프로젝트

## 개발 환경
- Unity 6
- TextMeshPro

## 진행 상황
- [x] 기본 대화 시스템
- [x] 스크립트 데이터 포맷과 실행기 (say / label / jump / end)
- [x] 배경 이미지, 캐릭터 이미지 연출 (bg / show / hide, 페이드) — 이미지는 임시 placeholder
- [x] 사운드 (bgm / sfx, BGM 교체 페이드) — 소리는 임시 placeholder
- [x] 선택지와 분기 (choice, 라벨 점프)
- [x] 플래그와 엔딩 판정 (set / if, 선택 누적으로 엔딩 분기)
- [x] 타이틀/엔딩 화면, 타이틀부터 엔딩까지 한 판 흐름 연결

- [x] 실제 시나리오 입력 (교실/복도/옥상, 선택지 3곳, 엔딩 2개) — 이미지와 소리는 임시 placeholder
- [ ] 빌드 테스트와 정리

스크립트 포맷과 구조는 [Docs/script-format.md](Docs/script-format.md), 시나리오와 엔딩 분기는 [Docs/story.md](Docs/story.md) 참고.
